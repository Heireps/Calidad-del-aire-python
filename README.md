# Proyecto: Clasificación de la calidad del aire

Este proyecto aplica técnicas de ciencia de datos para predecir la calidad del aire usando un dataset público. Se realiza análisis exploratorio, limpieza, entrenamiento de dos modelos (Random Forest y KNN) y su comparación.

## Archivos

- `01 - exploración.ipynb`: Análisis exploratorio del dataset.
- `02 - preprocesado.ipynb`: Limpieza de datos y creación de la variable objetivo.
- `03 - modelo 1.ipynb`: Entrenamiento y evaluación del modelo Random Forest.
- `04 - modelo 2.ipynb`: Entrenamiento y evaluación del modelo KNN.
- `05 - comparación.ipynb`: Comparación entre los modelos.
- `06 - dataset.csv`: Dataset utilizado.
- `07 - informe.pdf`: Informe final del proyecto.
